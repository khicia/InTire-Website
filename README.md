# InTIRE 🛞

**InTIREly safe in every drive.**

InTIRE is a web platform developed as part of an academic research project focused on **tire safety and visible tire defect inspection**. It supports users in becoming more aware of potential tire issues through an accessible and user-friendly interface.

## Features

* 🛞 Tire defect awareness and inspection
* 🧠 AI-powered tire defect detection
* 📱 Responsive web design
* 🌓 Light and dark mode
* 👨‍💻 Information about the InTIRE system and developers

## Research Project

**InTIRE: A Mobile Application for Tire Defect Inspection Using Deep Learning and CNN-Powered Image Detection**

> InTIRE is intended as an assistance tool and does not replace professional tire inspection.
